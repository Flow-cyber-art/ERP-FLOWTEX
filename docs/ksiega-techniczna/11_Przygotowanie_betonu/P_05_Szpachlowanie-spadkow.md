# Szpachlowanie spadków

- **Kod:** P/5
- **Producent:** TREMCO
- **Grupa:** Przygotowanie betonu
- **Wersja:** v1

## Warstwy

| Warstwa | Materiał | Dawka |
|---|---|---|
| Przygotowanie podłoża | Szlifowanie lub frezowanie + odkurzanie odkurzaczem podciśnieniowym | — |
| Pomiar i repery | Pomiar geodezyjny, linie spływu, repery wysokościowe | — |
| Grunt | Protop 1000 | 0.40 kg/m² |
| Zasyp gruntu | Piasek kwarcowy 0,4-0,8 mm (lekki, na mokry grunt) | 0.50 kg/m² |
| Zaprawa spadkowa - żywica | Protop 1000 | 2.50 kg/m² |
| Zaprawa spadkowa - kruszywo | Mieszanka piasków kwarcowych o różnym uziarnieniu | 20.00 kg/m² |

## Uwagi

- Spadek 1,5% w układzie kopertowym od ścian do kratki ściekowej; zacieranie mechaniczne lub ręczne.
